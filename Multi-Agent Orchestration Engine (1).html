Agents here are deterministic in-browser workers (regex extraction and a rule-based regulatory map) so the demo runs with no API key. The orchestration layer (planner, dependency scheduler, parallelism, retries with backoff, event trace) is the real part; each worker is a function you can swap for an LLM call.
